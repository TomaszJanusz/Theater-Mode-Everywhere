# AMO Listing - zh_CN

## Name
Theater Mode Everywhere - 剧场模式

## Summary
将任何 HTML5 视频缩放到浏览器窗口中。使用您自己的控件、字幕并与流行网站集成。

## Description
Theater Mode Everywhere 放大 HTML5 播放器以填充整个浏览器窗口，提供便捷的影院体验，无需标题、侧边栏、评论和推荐。

使用自定义播放控件观看教程、直播、视频和短片。利用字幕、键盘快捷键、图像和音量控制以及受支持平台上提供的其他功能。

可选的 Rich Theater Experience 添加了与 YouTube、Vimeo、Patreon、Twitch 和 Disney+ 的更深入集成。根据站点的不同，扩展程序可能会在时间线上显示字幕、章节、缩略图预览和其他信息。该功能仍处于实验阶段，因此其功能因平台而异。

主要特点
- 一键沉浸式模式：按 `T` 即可立即将活动视频放大到浏览器视图中。再按一次或 `Escape` 返回。如果页面有多个视频，可以使用`Shift+T`进行切换。
- 更好的字幕支持：直接在影院模式下选择曲目，使用 `C` 键打开和关闭字幕，并调整字体、大小、颜色、阴影、背景和不透明度。该扩展程序会分别记住每个网站的首选语言。
- Rich Theater Experience（实验性）：启用与 YouTube、Vimeo、Patreon、Twitch 和 Disney+ 的其他集成。可用功能取决于网站，可以在扩展弹出窗口或设置中进行管理。
- 更丰富的时间轴：在章节之间跳转，在快进或快退之前查看缩略图，并且在 YouTube 上还可以查看视频中播放次数最多的部分。
- 视频适合：按 `Z` 或使用播放器中的按钮切换适合、填充和拉伸并删除黑条，无需额外扩展。
- 优雅的自定义控件：现代控制栏，带有垂直音量和播放速度面板、半透明工具提示以及剩余和播放时间指示器。
- 音量增强（高达 300%）：使用 Web Audio API 将音量较小的视频的音频增强高达 300%，并使用非线性滑块进行精确设置和选项切换。
- 视觉 HUD：优雅的动画叠加，用于更改音量、快进或快退以及切换播放/暂停。
- Shadow DOM 支持：查找并放大隐藏在现代 Shadow root 中的播放器，提高与更多站点的兼容性。
- 自定义快捷键和设置：配置按键以切换影院模式、快进或快退、管理字幕、调整字幕大小和逐帧移动。播放器内帮助可帮助您检查所有快捷方式。
- 排除列表：通过浏览器栏或选项页面中的弹出窗口排除特定域，以避免与本机页面布局发生冲突。

操作
- 通用 HTML5 视频：适用于网络上的标准 HTML5 视频元素，包括放置在 Shadow DOM 中的播放器。
- 嵌入式播放器：检测并放大嵌入框架中的视频，例如 YouTube 或 Vimeo 播放器。
- HTML5 字幕：在自己的影院模式叠加层中显示标准 HTML5 字幕轨道，以便您可以自定义其外观。
- 平台集成：Rich Theater Experience 可以在 YouTube、Vimeo、Patreon、Twitch 和 Disney+ 上添加字幕、章节、预览缩略图等。功能范围取决于服务和视频。
- 现场广播：识别现场广播，如果该服务提供 DVR 窗口，则允许您倒回录制内容并返回到当前时刻。
- 受DRM保护的服务：某些平台限制播放器的访问，因此某些功能可能无法使用。

如何开始
1. 打开视频网站，例如流媒体平台、新闻网站或博客。
2. 按 `T` 进入影院模式。确保您没有在文本框中书写。
3. 使用播放器控件或快捷键：`C` 打开和关闭字幕、`Left` 和 `Right` 快进或快退，可配置的逐帧快捷键用于逐帧移动。
4. 在支持的平台上，在扩展弹出窗口或设置中启用 Rich Theater Experience。
5. 再次按 `Escape` 或 `T` 退出影院模式。
