# AMO Listing - ja

## Name
Theater Mode Everywhere

## Summary
ほとんどのウェブサイトで、動画をもっと大きく、気を散らさずに楽しめます。T キーを押すだけで、動画がウィンドウいっぱいに広がります。

## Description
Theater Mode Everywhere を使えば、キーをひとつ押すだけで、ページ上の気が散るものから解放されます。TME があれば、動画を見るのがもっと快適になります。この拡張機能で、動画をブラウザーのタブいっぱいに広げられます。ウェブのあちこちにある動画を、いつも同じ使い心地のプレーヤーで楽しめます。お気に入りの動画配信サービスならではの機能も、対応している可能性が高いので、どうぞご安心ください :-)

この表示を「シアターモード」と呼びます。お好きな動画のページで T キーを押して、ぜひ試してみてください。

要点
- ほとんどのサイトで同じように使えるシンプルなコントロール：字幕、再生速度、オプションの音量ブースト（最大300%）。
- 黒帯は「画面いっぱい」か「引き伸ばし」で消せるほか、動画を上に寄せて字幕用のスペースを作ることもできます。
- Rich Theater Experience を使うと、YouTube、Netflix、Disney+、Crunchyroll で動画の横のチャット、スキップボタン、チャプター、タイムラインのプレビューといった追加機能を利用できます。
- 無料でオープンソース、アナリティクスなし。あなたや視聴内容に関する情報が開発者に送信されることはありません。

人気サービスで使える追加機能
Rich Theater Experience（試験運用）があれば、シアターモードに切り替えても各サービスならではの機能を引き続き使えます。サービスごとのオン/オフは、ツールバーのポップアップまたは「設定」で切り替えられます。
- YouTube：動画の横のチャット（ライブまたはリプレイ）、チャプター、タイムラインのプレビュー、「Most Replayed」、音声トラック、動画の終了時に表示されるおすすめ動画。
- Netflix：「イントロをスキップ」と「次のエピソード」ボタン、さらに吹き替え版、オリジナル版、音声解説の各トラック。
- Disney+：「スキップ」と「次のエピソード」ボタン、さらに音声解説を含む音声トラック。
- Crunchyroll：イントロとクレジットのマーカー、プレビュー、「スキップ」と「次のエピソード」ボタン、字幕の選択（動画に焼き付けられた字幕はそのまま表示されます）。
その他の対応サービス：
- Vimeo：チャプター、プレビュー、ショーケース内の次の動画。
- Patreon：字幕、チャプター、プレビュー。
- SOOP（sooplive.com）：動画の横のチャットと、タイトルへの配信者名の表示。録画ではチャプターと、前後の録画への移動。
- Bilibili：字幕（Bilibili のログインが必要なものもあります）、チャプター、プレビュー、再生リスト、動画の終了時に表示されるおすすめ動画。
- Bilibili.tv：字幕、プレビュー、イントロとアウトロのマーカー。エピソードでは「スキップ」と「次のエピソード」ボタン。
- Tencent Video / WeTV：字幕、プレビュー、次のエピソード。
- iQIYI（iq.com）：シリーズとエピソードのタイトル、字幕と音声トラック、イントロとアウトロのマーカー、前後のエピソード。
- Rakuten Viki：エピソードのすべての字幕言語、吹き替えエピソードの音声トラック、プレビュー、「イントロをスキップ」と「次のエピソード」ボタン。
- Twitch：動画の横のチャット（ライブまたはリプレイ）、過去の配信のプレビューと字幕。

主な機能
- 動画のフィット：Z キーで「全体を表示」、「画面いっぱい」（端が切れます）、「引き伸ばし」を切り替えます。動画よりも縦に長い画面では「上寄せ」（Shift+L）で動画を上に寄せ、下の余白に字幕を表示できます。
- 字幕と音声：字幕トラックと音声トラックを選び、C キーで字幕のオン/オフを切り替え、フォント、サイズ、色、背景を調整できます。選んだ言語は記憶されます。
- オプションのオーディオエフェクト：音量ブースト（最大300%）、音声強調、大きな音を抑える、低音。
- キーボード（シアターモード中）：YouTube と同じ再生速度キー、右矢印キーの長押しで2倍速、カンマ（,）とピリオド（.）でコマ送り、W/A/S/D キーでコントロール間を移動。H キーで全ショートカットを一覧表示でき、どれも変更できます。
- コントロールと見た目：動画タイトルの表示、音量と再生速度のスライダー、動画の終了時に表示される「もう一度再生」画面。Shift+H でコントロールを表示したままにできます。アクセントカラーを選べるほか、「ハイコントラスト」「透明度を下げる」「動きを減らす」にも対応します。インターフェースは15言語に対応しています。
注意：機能はサービスや動画によって異なります。音量ブーストを含むオーディオエフェクトは、Netflix や Disney+ など DRM で保護された動画では動作しません。サイト側でブロックされている場合も同様です。

はじめかた
インストールしたら、動画のあるページを開いて T キーを押します（テキスト入力欄への入力中は除く）。ページに動画が複数あるときは Shift+T で切り替え、T キーまたは Escape キーでシアターモードを終了します。動画の上に表示するオプションのシアターモードボタン（ベータ版）を追加することもできます。AutoTheater をオンにすると、Rich Theater Experience を有効にしたサービスで、キャンセルできるカウントダウンのあとに自動でシアターモードに入ります。ツールバーのポップアップから、サイトごとに拡張機能をオフにできます。短いセットアップ（任意）では、視聴スタイルの好みを尋ねます。

プライバシー、無料、オープンソース
あなたや視聴内容に関する情報が、開発者や無関係な第三者に送信されることはありません。アナリティクスは使用していません。この拡張機能は、動画を見つけるためにすべてのウェブサイトへのアクセス権限を必要としますが、閲覧したページの一覧は保存しません。一部の機能は、字幕やプレビューを視聴中のサービスから直接読み込みます。除外したサイトやサイトごとの言語を含む設定は、ブラウザーのアカウントを通じて同期されることがあります。プライバシーポリシーは「設定」の「このツールについて」にあります。
Theater Mode Everywhere は無料で、これからもずっと無料です。MIT ライセンスのオープンソースです。

ここに挙げたサービスとは提携しておらず、各サービスから承認を受けたものでもありません。
