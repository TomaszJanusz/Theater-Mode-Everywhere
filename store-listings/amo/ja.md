# AMO Listing - ja

## Name
Theater Mode Everywhere - シアターモード

## Summary
HTML5 ビデオをブラウザ ウィンドウに拡大表示します。独自のコントロール、字幕を使用し、人気のある Web サイトと統合します。

## Description
Theater Mode Everywhere は、HTML5 プレーヤーをブラウザ ウィンドウ全体に拡大し、ヘッダー、サイドバー、コメント、推奨事項なしで便利な映画体験を提供します。

カスタム再生コントロールを使用して、チュートリアル、ストリーム、ビデオ、短いクリップを視聴します。字幕、キーボード ショートカット、画像と音量のコントロール、サポートされているプラ​​ットフォームで利用できる追加機能を活用します。

オプションの Rich Theater Experience を使用すると、YouTube、Vimeo、Patreon、Twitch、Disney+ とのより深い統合が追加されます。サイトによっては、拡張機能により、タイムラインに字幕、チャプター、サムネイル プレビュー、および追加情報が表示される場合があります。この機能はまだ実験段階であるため、その機能はプラットフォームによって異なります。

主な特徴
- ワンキーイマーシブ モード: `T` を押すと、アクティブなビデオが即座にブラウザ ビューに拡大されます。もう一度押すか `Escape` を押すと戻ります。ページ上に複数のビデオがある場合は、`Shift+T` を使用してそれらを切り替えます。
- より優れた字幕サポート: シネマ モードでトラックを直接選択し、`C` キーで字幕のオン/オフを切り替え、フォント、サイズ、色、影、背景、不透明度を調整します。拡張機能は、Web サイトごとに優先言語を個別に記憶します。
- Rich Theater Experience (実験的): YouTube、Vimeo、Patreon、Twitch、Disney+ との追加の統合を有効にします。利用可能な機能は Web サイトによって異なり、拡張機能のポップアップまたは設定で管理できます。
- より充実したタイムライン: チャプター間を移動し、シークする前にサムネイルを表示します。また、YouTube では、ビデオの最も再生されている部分も確認できます。
- ビデオ フィット: `Z` を押すか、プレーヤーのボタンを使用して、フィット、フィル、ストレッチを切り替え、追加の拡張を行わずに黒いバーを削除します。
- エレガントなカスタム コントロール: 垂直方向の音量と再生速度のパネル、半透明のツールチップ、残り時間と再生時間のインジケーターを備えたモダンなコントロール バー。
- 音量ブースト (最大 300%): Web オーディオ API を使用して、音量の小さい動画の音声を最大 300% までブーストします。非線形スライダーで正確な設定を行い、オプションを切り替えます。
- ビジュアル HUD: 音量変更、シーク、再生/一時停止の切り替えのためのエレガントなアニメーション オーバーレイ。
- Shadow DOM サポート: 最新のシャドウ ルートに隠れているプレーヤーを見つけて拡大し、より多くのサイトとの互換性を向上させます。
- カスタムショートカットと設定: シアターモードの切り替え、シーク、字幕の操作、字幕のサイズ変更、フレーム送りを行うためのキーを設定します。プレーヤー内のヘルプは、すべてのショートカットを確認するのに役立ちます。
- 除外リスト: ネイティブ ページ レイアウトとの競合を避けるために、ブラウザ バーまたはオプション ページのポップアップを介して特定のドメインを除外します。

操作
- ユニバーサル HTML5 ビデオ: Shadow DOM に配置されたプレーヤーを含む、Web 上の標準的な HTML5 動画要素で動作します。
- 埋め込みプレーヤー: YouTube や Vimeo プレーヤーなど、フレームに埋め込まれたビデオを検出して拡大します。
- HTML5 字幕: 標準的な HTML5 字幕トラックを独自のシネマ モード オーバーレイで表示し、外観をカスタマイズできます。
- プラットフォーム統合: Rich Theater Experience は、YouTube、Vimeo、Patreon、Twitch、Disney+ に字幕、チャプター、プレビュー サムネイルなどを追加できます。機能の範囲はサービスと動画によって異なります。
- ライブ ブロードキャスト: ライブ ブロードキャストを認識し、サービスが DVR ウィンドウを提供している場合は、録画を巻き戻して現在の瞬間に戻ることができます。
- DRM で保護されたサービス: 一部のプラットフォームではプレーヤーへのアクセスが制限されているため、一部の機能が利用できない場合があります。

始め方
1. ストリーミング プラットフォーム、ニュース サイト、ブログなどのビデオ サイトを開きます。
2. `T` を押してシネマモードに入ります。テキストボックスに何も書き込んでいないことを確認してください。
3. プレーヤー コントロールまたはショートカットを使用します。`C` は字幕のオンとオフを切り替え、`Left` と `Right` でシークし、`<` と `>` でコマ送りします。
4. サポートされているプラ​​ットフォームでは、拡張機能のポップアップまたは設定で Rich Theater Experience を有効にします。
5. `Escape` または `T` をもう一度押して、シアター モードを終了します。
