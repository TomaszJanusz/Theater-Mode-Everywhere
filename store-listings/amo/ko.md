# AMO Listing - ko

## Name
Theater Mode Everywhere

## Summary
모든 HTML5 영상을 브라우저 가득 확대합니다. 맞춤 컨트롤, 자막, 오디오 효과, 동영상 서비스 연동을 사용해 보세요.

## Description
Theater Mode Everywhere는 HTML5 플레이어를 브라우저 창 전체로 확대해 헤더, 사이드바, 댓글, 추천 영상 없이 편안한 영화관 같은 시청 환경을 제공합니다.

강의, 라이브 방송, 영상, 짧은 클립을 맞춤 재생 컨트롤로 즐겨 보세요. 자막, 키보드 단축키, 영상 맞춤, 오디오 효과, 음량 컨트롤을 쓸 수 있고, 지원되는 플랫폼에서는 추가 기능도 사용할 수 있습니다.

Rich Theater Experience(RTE)는 인기 있는 온라인 서비스와 더 깊이 연동합니다. YouTube와 Twitch에서는 화면 옆 채팅을, Netflix와 Disney+에서는 인트로 건너뛰기 버튼과 다음 에피소드 이동을, Bilibili(중국판과 국제판 모두)에서는 제목, 자막, 타임라인의 미리보기 썸네일을 추가합니다. 서비스에 따라 제목, 자막, 챕터, 미리보기 썸네일, 건너뛰기 버튼, 다음 에피소드 이동, 타임라인의 추가 정보를 표시할 수 있습니다. 플랫폼에 따라 지원 범위가 다릅니다. 지원하는 서비스의 전체 목록은 확장 프로그램 설정에서 확인할 수 있습니다.

주요 기능
- 키 하나로 몰입 모드: `T` 키를 누르면 현재 영상이 즉시 브라우저 화면 크기로 확대됩니다. 다시 누르거나 `Escape` 키를 누르면 돌아옵니다. 페이지에 영상이 여러 개 있다면 `Shift+T`로 전환하세요. 화면을 더블클릭하면 시어터 모드를 벗어나지 않고 전체 화면을 켜거나 끌 수 있습니다.
- 더 나은 자막 지원: 영화관 모드에서 바로 자막 트랙을 선택하고, `C` 키로 자막을 켜고 끄며, 글꼴, 크기, 색상, 그림자, 배경, 불투명도를 조절할 수 있습니다. 선호하는 언어는 웹사이트마다 따로 기억합니다.
- Rich Theater Experience: 지원되는 서비스와 추가 연동을 켭니다. 사용할 수 있는 기능은 서비스에 따라 다르며, 확장 프로그램 팝업이나 설정에서 서비스별 스위치로 관리합니다.
- 화면 옆 채팅: Rich Theater Experience를 쓰는 Twitch와 YouTube에서 라이브 채팅이나 채팅 다시보기를 영상 옆이나 아래에 두고, `Alt+R`로 표시하거나 숨길 수 있습니다.
- 더 풍부한 타임라인: 챕터 사이를 이동하고, 이동하기 전에 썸네일 미리보기를 확인하며, YouTube의 '가장 많이 다시 본 장면'을 볼 수 있습니다. 설치된 SponsorBlock 마커를 YouTube 타임라인에 표시할 수도 있습니다.
- 건너뛰기 버튼과 다음 에피소드: 서비스에서 제공하는 경우 인트로, 크레딧, 이전 줄거리 요약이나 YouTube 광고를 건너뛰고 이전 또는 다음 영상이나 에피소드로 이동할 수 있습니다.
- 영상 맞춤과 올린 레이아웃: `Z` 키나 플레이어의 버튼으로 맞춤, 채우기, 늘리기를 전환해 별도 확장 프로그램 없이 검은 여백을 없애세요. 올린 레이아웃(`Shift+L`)을 선택하면 화면이 위로 올라가고 그 아래 공간을 자막에 쓸 수 있습니다.
- 세련된 맞춤 컨트롤: 영상 제목, 세로형 음량 및 재생 속도 패널, 반투명 툴팁, 경과 시간과 남은 시간 표시를 갖춘 현대적인 컨트롤 바입니다. `Shift+H`로 컨트롤을 항상 표시할 수 있습니다.
- 오디오 효과: 플레이어 설정에서 음량 부스트(최대 300%), 음성 강조, 큰 소리 줄이기, 저음을 사용할 수 있으며 효과가 켜져 있는 동안에만 Web Audio API로 처리합니다. DRM으로 보호된 미디어에서는 사용할 수 없습니다.
- 시각적 HUD: 음량을 바꾸거나, 탐색하거나, 재생/일시정지를 전환할 때 세련된 애니메이션 오버레이를 보여 줍니다.
- AutoTheater(Rich Theater Experience): 지원되는 영상이 시작되면 자동으로 시어터 모드로 들어가며, 짧은 카운트다운 알림은 클릭하거나 `Esc`로 취소할 수 있습니다.
- 영상 실행 버튼(베타, 기본값 꺼짐): 일시정지된 영상 위의 작은 버튼으로 한 번의 클릭으로 시어터 모드에 들어갑니다. Rich Theater Experience를 쓰는 YouTube에서는 플레이어 도구 모음에 있습니다.
- Shadow DOM 지원: 최신 shadow root 안에 숨은 플레이어를 찾아 확대해 더 많은 사이트와 호환됩니다.
- 사용자 지정 단축키와 설정: 시어터 모드 전환, 탐색, 자막 관리, 자막 크기 조절, 프레임 단위 이동에 쓸 키를 설정할 수 있습니다. 설정에서 충돌하는 단축키를 알려 주고, 플레이어 안의 도움말로 모든 단축키를 확인할 수 있습니다. 언어, 강조 색상, 고대비, 투명도 줄이기, 동작 줄이기도 선택할 수 있습니다.
- 예외 목록: 브라우저 막대의 팝업이나 옵션 페이지에서 특정 도메인을 제외해 페이지 고유 레이아웃과의 충돌을 피하세요.

지원 범위와 작동 방식
- 범용 HTML5 영상: 웹의 표준 HTML5 video 요소에서 작동하며 Shadow DOM 안의 플레이어도 지원합니다.
- 삽입된 플레이어: YouTube나 Vimeo 플레이어처럼 프레임에 삽입된 영상을 감지해 확대합니다.
- HTML5 자막: 표준 HTML5 자막 트랙을 영화관 모드 전용 오버레이에 표시하므로 모양을 직접 꾸밀 수 있습니다.
- 플랫폼 연동: 설명 첫머리에 언급한 서비스 외에도 RTE는 Vimeo(재생목록과 Showcase 이동), Tencent Video(제목, 자막, 챕터), Patreon(직접 업로드한 영상이 있는 게시물에서 시어터 모드 자동 진입), Crunchyroll(제목, 인트로와 크레딧 챕터, 자막 선택) 등을 지원합니다. 사용할 수 있는 기능은 서비스와 영상에 따라 다릅니다.
- 라이브 방송: 라이브 방송을 인식하며, 서비스가 DVR 구간을 제공하면 녹화분을 되감았다가 현재 시점으로 돌아올 수 있습니다.
- DRM 보호 서비스: 일부 플랫폼은 플레이어 접근을 제한하므로 오디오 효과 같은 일부 기능은 사용하지 못할 수 있습니다.
- 개인정보 보호: 사용자는 상품이 아닙니다. 이 확장 프로그램은 사용자 정보나 시청 내용을 개발자에게 전송하지 않습니다. 설정은 브라우저 계정을 통해 동기화될 수 있습니다. 개인정보 처리방침 전문은 설정의 정보 탭에서 볼 수 있습니다.
- 무료 오픈 소스: Theater Mode Everywhere는 무료이며 앞으로도 계속 무료입니다. 소스 코드도 공개되어 있습니다.

시작하는 방법
1. 스트리밍 플랫폼, 뉴스 사이트, 블로그 등 영상이 있는 사이트를 엽니다.
2. `T` 키를 눌러 영화관 모드로 들어갑니다. 텍스트 입력란에 글을 쓰고 있지 않은지 확인하세요.
3. 플레이어 컨트롤이나 단축키를 사용하세요. `C`는 자막을 켜고 끄며, `Left`와 `Right`는 탐색하고, 설정 가능한 프레임 이동 단축키는 한 프레임씩 이동합니다.
4. 지원되는 플랫폼에서는 확장 프로그램 팝업이나 설정에서 Rich Theater Experience를 켭니다.
5. `Escape` 또는 `T`를 다시 누르면 시어터 모드가 종료됩니다.
