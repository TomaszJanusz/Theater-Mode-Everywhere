Theater Mode Everywhere 可将 HTML5 播放器放大至整个浏览器窗口，提供没有页眉、侧边栏、评论和推荐内容干扰的舒适影院体验。

使用自定义播放控件观看教程、直播、视频和短片。可使用字幕、键盘快捷键、画面适配、音频效果和音量控制，在受支持的平台上还有更多附加功能。

Rich Theater Experience（RTE）可与常用的在线服务深度集成。在 YouTube、Twitch、Bilibili（含国内版和国际版）以及 Netflix、Disney+ 等影视服务上，RTE 能带来更好的观看体验。视服务而定，扩展程序可显示标题、字幕、章节、缩略图预览、跳过按钮、下一集导航以及时间轴上的更多信息。不同平台上的可用能力有所不同。支持的服务完整列表见扩展程序设置。

主要功能
- 一键沉浸模式：按 `T` 键即可立即将当前视频放大至整个浏览器窗口。再按一次或按 `Escape` 键即可返回。如果页面上有多个视频，可用 `Shift+T` 切换。双击画面即可进入或退出全屏，而无需退出剧场模式。
- 更好的字幕支持：直接在影院模式中选择字幕轨道，用 `C` 键开关字幕，并调整字体、大小、颜色、阴影、背景和不透明度。扩展程序会为每个网站分别记住您偏好的语言。
- Rich Theater Experience：为 受支持的服务启用附加集成。可用功能取决于服务，您可以在扩展程序弹出窗口或设置中为每项服务单独开关。
- 画面旁的聊天：在启用 Rich Theater Experience 的 Twitch 和 YouTube 上，可将直播聊天或聊天回放固定在视频旁边或下方，并用 `Alt+R` 显示或隐藏。
- 更丰富的时间轴：在章节之间跳转，在拖动前预览缩略图，并查看 YouTube 的“最多重放”片段。已安装的 SponsorBlock 标记可显示在 YouTube 时间轴上。
- 跳过按钮与下一集：在服务提供时，可跳过片头、片尾、剧情回顾或 YouTube 广告，并切换到上一个或下一个视频或剧集。
- 画面适配与上移布局：按 `Z` 键或使用播放器中的按钮，在适应、填充和拉伸之间切换，无需其他扩展程序即可去除黑边。选择上移布局（`Shift+L`），可将画面移到顶部，并用下方空间显示字幕。
- 精致的自定义控件：现代化控制栏，包含视频标题、竖向的音量和播放速度面板、半透明提示以及已播放和剩余时间指示。按 `Shift+H` 可让控件始终显示。
- 音频效果：在播放器设置中提供音量增强（最高 300%）、人声增强、降低响亮声音和低音，仅在效果开启时通过 Web Audio API 处理。DRM 保护的媒体不可用。
- 视觉 HUD：调整音量、快进快退以及切换播放/暂停时，显示精致的动画提示。
- AutoTheater(Rich Theater Experience)：受支持的视频开始播放时自动进入剧场模式，并显示简短的倒计时提示，可点击或按 `Esc` 取消。
- 视频启动按钮（测试版，默认关闭）：暂停的视频上的小按钮，一键进入剧场模式。在启用 Rich Theater Experience 的 YouTube 上，它位于播放器工具栏中。
- Shadow DOM 支持：查找并放大隐藏在现代 shadow root 中的播放器，提升对更多网站的兼容性。
- 自定义快捷键和设置：可设置切换剧场模式、快进快退、管理字幕、调整字幕大小以及逐帧步进的按键。设置会提示冲突的快捷键，播放器内的帮助可让您查看全部快捷键。还可选择语言、强调色、高对比度、降低透明度和减少动态效果。
- 排除列表：通过浏览器工具栏弹出窗口或选项页面排除特定域名，避免与页面原有布局冲突。

适用范围与工作方式
- 通用 HTML5 视频：适用于网络上的标准 HTML5 video 元素，包括位于 Shadow DOM 中的播放器。
- 嵌入式播放器：检测并放大嵌入在框架中的视频，例如 YouTube 或 Vimeo 播放器。
- HTML5 字幕：在影院模式专属的叠加层中显示标准 HTML5 字幕轨道，方便您自定义其外观。
- 平台集成：Rich Theater Experience 可在受支持的服务上添加标题、字幕、章节、缩略图预览等。除说明开头提到的服务外，还支持 Vimeo、腾讯视频、Patreon 和 Crunchyroll 等。可用功能取决于服务和视频。
- 直播：可识别直播，如果服务提供 DVR 窗口，您可以回放录像并返回当前时刻。
- DRM 保护的服务：部分平台限制访问播放器，因此音频效果等某些功能在这些平台上可能不可用。
- 隐私：您不是商品。本扩展程序不会向开发者发送有关您或您观看内容的任何信息。设置可通过浏览器账号同步。完整的隐私政策可在“设置”的“关于”中查看。
- 免费开源：Theater Mode Everywhere 免费，并将永远免费，源代码也已公开。

开始使用
1. 打开视频网站，例如流媒体平台、新闻网站或博客。
2. 按 `T` 键进入影院模式。请确认您当前没有在文本框中输入。
3. 使用播放器控件或快捷键：`C` 开关字幕，`Left` 和 `Right` 快进快退，可配置的逐帧快捷键用于逐帧移动。
4. 在受支持的平台上，于扩展程序弹出窗口或设置中启用 Rich Theater Experience。
5. 再次按 `Escape` 或 `T` 即可退出剧场模式。
